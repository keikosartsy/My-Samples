This version of the AI Avatar Interrogator (AAI) Project is an incomplete prototype and should not be considered representative of the final product.

Most basic functions work well, but many changes made later in production -- such as reorganizing files, separating related functions into their own .py files, and storing personalities in a separate file -- are not implemented here.

The purpose of uploading this code is to demonstrate the project's base features.

You will need Google Cloud CLI with appropriate permissions and credentials to utilize any Gemini-based services such as TTS/STT and Gemini responses.
